# GLAME APP — фиксированная спецификация блока 2 Главной страницы

## Блок 2: «Новое в GLAME»

Этот блок зафиксирован как постоянный шаблон в конструкторе приложения.

В дальнейшем через конструктор можно менять только:

- фотографии;
- название дропа;
- описание дропа;
- товары;
- названия товаров;
- наличие / город / доставка;
- цены, если они добавляются в карточки.

Нельзя менять:

- структуру блока;
- размеры зон;
- расположение кнопок;
- расположение ссылки «Все новинки»;
- расположение карточек;
- радиусы;
- обводки;
- тип иконки избранного;
- общую композицию editorial-commerce.

---

## Роль блока в CJM

Блок 2 идет сразу после первого hero-carousel.

Его задача: перевести пользователя из вдохновения в ассортимент.

Логика:

1. Пользователь увидел GLAME и сценарии выбора.
2. Пользователь скроллит ниже.
3. Видит живое поступление / дроп.
4. Может открыть конкретный дроп.
5. Может сохранить товар в «Мой стиль».
6. Может перейти во все новинки.

---

## Общая структура блока

Порядок элементов всегда один и тот же:

1. Верхний header приложения.

4. Короткое описание блока.

### Логика иконки избранного

Иконка не добавляет товар в корзину.

Она сохраняет товар в «Мой стиль» / избранное:

```dart
toggleFavorite(productId)
```

Если пользователь не авторизован:

- товар временно сохраняется локально;
- авторизация предлагается мягко позже;
- не блокировать сохранение сразу.

## Переходы

### «Все новинки»

Ведет в общий раздел новинок:

```dart
navigateToCatalog(filters: {
  isNew: true,
})
```

### «Смотреть дроп»

Ведет на страницу конкретного дропа:

```dart
navigateToDrop(dropId)
```

### Клик по карточке товара

Ведет в карточку товара:

```dart
navigateToProduct(productId)
```

### Иконка heart / bookmark

Сохраняет в избранное:

```dart
toggleFavorite(productId)
```

## Запреты

- Не превращать блок в маркетплейсную сетку.
- Не менять порядок: header → drop card → product cards.
- Не использовать символ «+» для избранного.
- Не использовать скругленные карточки.
- Не использовать тени.
- Не использовать glow.
- Не использовать цветные ecommerce-бейджи.
- Не двигать «Все новинки».
- Не двигать «Смотреть дроп».
- Не двигать иконки избранного.
- Не менять количество основных товарных карточек без отдельного утверждения.
- Не использовать агрессивные CTA вроде «Купить сейчас», «Успейте», «Акция».
- Не писать наличие как барьер: «только в Ялте», «нет в Симферополе».
- Формулировать наличие сервисно: «В Ялте · доставка по России», «В наличии · доставка по России», «Можно забронировать».

## Итоговое правило

Блок «Новое в GLAME» является фиксированным шаблоном.

В дальнейшем можно менять только контент внутри утвержденных зон.  
Структура, сетка, кнопки, карточки, отступы, радиусы и логика переходов остаются без изменений.
