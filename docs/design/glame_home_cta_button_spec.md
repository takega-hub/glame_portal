# GLAME APP — параметры CTA-кнопок первого блока Главной

## Главное правило

Все кнопки на слайдах первого блока Главной страницы находятся в едином фиксированном месте — как на первом слайде.  
Кнопки не двигаются под композицию конкретного фото.

Кнопки добавляются в конструкторе приложения отдельно, поэтому в фоновых изображениях нужно оставлять под них свободную зону.

## Primary CTA

Используется для главного действия:

- Собрать свой стиль
- Смотреть подборку
- Начать подбор

### На темном / фотофоне

| Параметр | Значение |
|---|---|
| Заливка | #FFFFFF |
| Текст | графитовый / #242424–#303030 |
| Обводка | #FFFFFF, 1 px |

### На светлом фоне

| Параметр | Значение |
|---|---|
| Заливка | графитовая / #2F3030 |
| Текст | #FFFFFF |
| Обводка | #2F3030, 1 px |

## Secondary CTA

Используется для второго действия:

- Смотреть новинки
- Подобрать под меня
- Смотреть украшения
- Написать стилисту

| Параметр | Значение |
|---|---|
| Заливка | прозрачная |
| Обводка | 1 px |
| Текст | цвет обводки |
| На темном / фотофоне | #FFFFFF |
| На светлом фоне | #2F3030 |

## Запреты

- Не менять положение кнопок от слайда к слайду.
- Не делать разные размеры кнопок в одной карусели.
- Не использовать скругление.
- Не добавлять тени, glow, blur, градиент на кнопку.
- Не вшивать кнопки в фоновые изображения, если они добавляются конструктором.
- Не вшивать верхнее и нижнее меню в фоновые изображения.
- Не использовать графический паттерн в верхнем и нижнем меню.
