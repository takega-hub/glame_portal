# 05. GLAME — Home Block 3 / AI-подбор по фото

## Роль

Третий блок Главной должен фокусироваться только на одном сильном сценарии:

```text
Подбор по фото / AI-анализ внешности для выбора украшений
```

---

## Что входит

Блок объясняет:
- можно загрузить или сделать фото;
- GLAME подберет формы, линии и масштаб украшений;
- подбор учитывает внешность, пропорции, цвет, фактуру, посадку, стиль.

---

## Что НЕ входит в этот блок

Не смешивать с:
- подарками;
- match to product;
- размером;
- событием;
- “не знаю, с чего начать”;
- общим подбором стилиста.

Эти сценарии могут быть ниже или в отдельных flows.

---

## Формулировки

Не раскрывать грубо “мы анализируем лицо”.  
Мягкая формулировка:

```text
Подбор форм, линий, масштаба и стиля по фото.
```

Можно использовать:
- форма;
- масштаб;
- линии;
- пропорции;
- цвет;
- фактура;
- общий стиль.

---

## Auth rule

Без регистрации/авторизации фото не загружается.

Если пользователь не авторизован:
- показать authorization gate;
- объяснить, что фото сохраняется/обрабатывается только после входа;
- не открывать галерею/камеру до auth.

Если авторизован:
- `Загрузить или сделать фото` открывает camera/gallery;
- `Какое фото подойдет` открывает короткую инструкцию.

---

## Developer note

Параметры анализа для внутренней логики:
- форма лица;
- пропорции;
- масштаб черт;
- цветовой контраст;
- тон кожи/температура;
- фактура внешности;
- посадка серьги / мочка / размер;
- длина шеи / зона декольте при необходимости;
- общий стиль;
- предпочтения пользователя.

Не показывать весь список как публичный технический UI-блок.
