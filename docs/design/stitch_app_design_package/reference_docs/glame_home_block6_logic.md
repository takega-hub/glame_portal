# GLAME App — Главная / 6-й блок «Как выбрать и купить»

## 1. Назначение блока

6-й блок — финальный сервисный блок Главной страницы GLAME.

Блок **не ведет на отдельную сервисную страницу** и не должен превращаться в FAQ.  
Его задача — сразу дать покупателю 3 способа действия и снять страх онлайн-заказа.

Блок отвечает на вопрос:

> Как спокойно выбрать и купить украшение в GLAME онлайн?

---

## 2. Согласованный визуальный принцип

Финальный дизайн зафиксирован как графитовый архитектурный mobile-block с объемным GLAME-pattern.

Обязательные правила:

- mobile-first;
- графитовый архитектурный фон;
- volumetric GLAME-pattern вместо слогана;
- холодная палитра: graphite / steel gray / cold light;
- без теплых оттенков;
- без иконок;
- radius `0 px`;
- stroke / border `1 px`;
- clean geometric typography / Clinica Pro;
- action-panels выглядят как основные CTA;
- сервисная зона — 2×2;
- стиль: digital continuation of GLAME spaces.

```text
Как выбрать
```

```text
Онлайн-заказ в GLAME не должен быть покупкой вслепую. Мы поможем выбрать украшение спокойно — до оплаты и во время примерки.
```

## 4. Action-panels

В блоке 3 кликабельные панели.  
Кликабельна **вся панель**, не только стрелка.

### 01 Самостоятельно

Описание:

```text
Каталог, бренды и подборки.
```

Действие:

```dart
context.push('/catalog');
```

---

### 02 С живым стилистом

Описание:

```text
Онлайн или в пространстве.
```

Действие:

```dart
openStylistContact(source: 'home_block_6');
```

Статус стилиста рассчитывается по московскому времени.

Рабочее время:

```text
10:00–20:00 по МСК
```

В рабочее время показывать:

```text
На связи сейчас · до 20:00 по МСК
```

В нерабочее время показывать:

```text
Сейчас не на связи · с 10:00 по МСК
```

#### Bottom sheet в рабочее время

Заголовок:

```text
Стилист GLAME
```

Текст:

```text
Опишите задачу — стилист поможет подобрать украшение онлайн или пригласит в пространство, если нужна примерка.
```

CTA:

```text
Связаться со стилистом
```

#### Bottom sheet в нерабочее время

Заголовок:

```text
Оставить заявку стилисту
```

Текст:

```text
Стилист GLAME ответит с 10:00 до 20:00 по МСК. Опишите задачу — мы подберем украшения под образ, повод или подарок.
```

CTA:

```text
Оставить заявку
```

Важно: не дублировать кнопку AI внутри bottom sheet. AI-подбор уже есть отдельной action-panel в этом же блоке.

---

### 03 Через AI-подбор

Описание:

```text
По фото, форме, масштабу и стилю.
```

Действие:

```dart
context.push('/selection/ai-photo');
```

Если пользователь не авторизован — показать authorization gate.  
Если авторизован — открыть сценарий загрузки фото.

## 5. Сервисная зона

Заголовок:

```text
Чтобы онлайн-покупка
была спокойной
```

Сервисная зона **не кликабельна**.  
Это reassurance-layer, а не меню и не FAQ.

### 01 Примерка перед покупкой

```text
Курьер привозит изделия для примерки: вы выбираете и оплачиваете только то, что подошло, остальное возвращается с курьером.
```

### 02 Детали до заказа

```text
Уточним размер, длину, застёжку, цвет, фактуру, вес и масштаб изделия.
```

### 03 Гарантия и уход

```text
Расскажем условия по конкретному изделию и подскажем, как за ним ухаживать.
```

### 04 Поддержка и Клуб стильных

```text
Можно обратиться в GLAME после покупки. Покупки участвуют в программе лояльности.
```

```json
{
  "source": "home_block_6",
  "scenario": "live_stylist",
  "created_at": "ISO_DATE",
  "working_hours_status": "open_or_closed",
  "user": {
    "is_authorized": true,
    "name": "string_or_null",
    "phone": "string_or_null",
    "city": "string_or_null"
  },
  "request": {
    "text": "string",
    "quick_tags": ["for_self", "gift", "look", "set", "try_in_space"],
    "favorite_product_ids": [],
    "source_product_id": null
  },
  "purchase_history": {
    "available": true,
    "last_purchases": [],
    "categories": [],
    "brands_or_lines": [],
    "metals_or_colors": [],
    "sizes": [],
    "average_item_price": null,
```

Это внутренний контекст для стилиста, не публичный UI-блок.
