# 01. GLAME — Identity & Anti-Distortion Rules

## Роль

Защитить айдентику GLAME от искажений в дизайне, генерации, верстке и Cursor.

GLAME — не “примерно минималистичный jewelry e-commerce”.  
GLAME — premium digital-пространство: бетон, стекло, металл, свет, воздух, архитектура, холодная палитра и точная геометрия.

---

## Логотип GLAME

### Разрешено
- Использовать только оригинальный asset логотипа.
- Масштабировать только пропорционально.
- Использовать утвержденные цветовые версии: graphite / white / steel / silver.

### Запрещено
- Перерисовывать логотип.
- Генерировать логотип через image generation.
- Набирать GLAME похожим шрифтом.
- Менять толщину, пропорции, расстояния, форму букв.
- Добавлять эффекты без согласования.

---

## Значок G

G-знак — не обычная буква G.  
У него есть собственная геометрия, верхний вертикальный элемент, внутренняя перекладина и объем.

### Разрешено
- Использовать только оригинальный asset.
- Масштабировать пропорционально.
- Использовать в bottom nav как approved icon asset.

### Запрещено
- Перерисовывать.
- Упрощать в flat icon.
- Делать похожую букву.
- Менять внутреннюю перекладину.
- Менять верхний элемент.
- Поворачивать.
- Растягивать.
- Генерировать.

---

## Реальные фото пространств

### Разрешено
- crop;
- exposure;
- contrast;
- cool color correction;
- sharpness;
- gradient overlay for readability.

### Запрещено
- дорисовывать фасад;
- дорисовывать интерьер;
- менять архитектуру;
- менять вывеску;
- менять мебель;
- менять витрины;
- менять материалы;
- смешивать Ялту и Симферополь;
- генерировать “похожий магазин”.

Фотография пространства — доказательство доверия. Любое искажение снижает доверие.

---

## Паттерн GLAME

### Разрешено
- использовать согласованный GLAME-pattern;
- кропить;
- делать объем / тень / emboss;
- использовать как архитектурную фактуру.

### Запрещено
- поворачивать паттерн;
- ставить под углом;
- искажать буквы;
- перестраивать случайно;
- использовать как декоративные “обои”.

Правило:

```text
Pattern must stay aligned to vertical/horizontal axes.
Only light/shadow may be diagonal, not the pattern itself.
```

---

## Цвет

База:
- Graphite `#222426`
- Near black `#0E1012`
- Steel gray `#8E9397`
- Cold light gray `#C7CBCF`
- White `#EFF1F2`
- Border gray `#5C6064`

Запрещено:
- warm beige UI;
- gold UI accents;
- marketplace shadows;
- glow;
- pill buttons.

---

## Геометрия

- Radius: `0 px`
- Border: `1 px`
- Clean grid
- Straight angles
- No decorative UI

Запрещено:
- rounded cards;
- pill buttons;
- glassmorphism;
- мягкие ecommerce-тени;
- случайные иконки.

---

## Image generation

Image generation нельзя использовать для production-сборки:
- логотипа;
- G-знака;
- реальных магазинов;
- нижнего меню;
- top bar;
- точного UI-screen;
- фирменного паттерна.

Production screen должен собираться как layout/composite из approved assets.
