# 07. GLAME — Home Block 5 / Spaces

## Роль

Блок пространств показывает GLAME как реальные physical spaces.  
Это trust layer и brand atmosphere.

---

## Пространства

### Ялта

Позиционирование:
- пространство у моря;
- свет;
- воздух;
- море;
- promenade / resort feeling.

Использовать только реальные фото Ялты.

### Симферополь

Позиционирование:
- пространство городского стиля и ритма;
- графитовое;
- архитектурное;
- собранное;
- город, форма, свет, характер пространства.

Использовать только реальные фото Симферополя.

---

## Запреты

- Не смешивать Ялту и Симферополь.
- Не использовать фото Ялты для Симферополя.
- Не использовать фото Симферополя для Ялты.
- Не дорисовывать интерьер.
- Не менять вывеску.
- Не менять мебель.
- Не менять пропорции пространства.
- Не генерировать “похожий” магазин.

---

## Navigation

Страница пространства должна иметь единый navigation logic:
- back to spaces должен быть одинаково решен для Ялты и Симферополя;
- если кнопка есть в Симферополе, она должна быть и в Ялте или логика должна быть явно другой;
- не допускать рассинхрона UI.

---

## Visual tone

- Yalta: light, air, sea.
- Simferopol: graphite, architecture, city rhythm.

Оба пространства должны оставаться GLAME, но с разным характером.
