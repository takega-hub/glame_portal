# 11. GLAME — Spaces / Yalta & Simferopol Rules

## Роль

Отдельный модуль для правил пространств GLAME.

Цель — сохранить доверие: покупатель должен видеть реальные пространства, а не сгенерированную картинку.

---

## Ялта

Позиционирование:

```text
пространство у моря
```

Ключи:
- свет;
- воздух;
- море;
- promenade;
- resort;
- мягкая холодная эстетика;
- стекло / вода / отражения.

Использовать только фото Ялты.

---

## Симферополь

Позиционирование:

```text
пространство городского стиля и ритма
```

Ключи:
- графит;
- архитектура;
- город;
- форма;
- свет;
- собранность;
- city rhythm.

Использовать только фото Симферополя.

---

## Запреты

- Не смешивать фото Ялты и Симферополя.
- Не использовать одно пространство как другое.
- Не дорисовывать интерьер.
- Не дорисовывать фасад.
- Не менять вывеску.
- Не менять мебель.
- Не менять материалы.
- Не менять пропорции.
- Не генерировать альтернативный магазин.
- Не “улучшать” архитектуру через AI.

---

## Allowed editing

- exposure;
- contrast;
- cold color correction;
- sharpness;
- crop;
- gradient overlay for readability.

---

## Page logic

Страницы пространств должны быть единообразны:
- одинаковая navigation logic;
- одинаковая back-to-spaces logic;
- одинаковая typography hierarchy;
- разная эмоциональная температура по городу.

Если на странице Симферополя есть `вернуться к пространствам`, в Ялте должна быть такая же логика или явно утвержденное отличие.

---

## Developer/Cursor rule

```text
Do not generate GLAME spaces.
Use provided real photos only.
Preserve architecture, signage, furniture, materials, lighting, and city attribution.
```
