# 04. GLAME — Home Block 2 / «Новое в GLAME»

## Роль

Второй блок — transition из emotional hero в exploration/product discovery.

Это не маркетплейсная сетка.  
Это editorial-commerce block.

---

## Структура Variant B — зафиксирована

Обязательная структура:
1. Header: `Новое в GLAME`
2. Short description
3. Link: `Все новинки`
4. One large drop/editorial card
5. Product cards below

---

## Запреты

- Не превращать в generic marketplace grid.
- Не дробить в слишком много мелких карточек.
- Не использовать rounded ecommerce cards.
- Не использовать marketplace shadows/glow.
- Не менять structure, block proportions, card layout, button locations.
- Не использовать `+` как favorite/save icon, потому что читается как add-to-cart.

---

## Fixed interactive elements

- `Все новинки` — top-right of block header.
- `Смотреть дроп` — inside large drop card in approved position.
- Save/favorite icon — lower product-card zone.
- Buttons: radius 0 px, 1 px border.

---

## Visual system

- cold GLAME palette;
- radius 0;
- thin borders;
- clean geometry;
- no shadows;
- no marketplace style;
- only product/photo content may change through constructor.

---

## Constructor rule

В будущем через конструктор можно заменять:
- фото;
- продукты;
- названия;
- цены;
- product content.

Нельзя менять:
- structure;
- proportions;
- spacing;
- typography hierarchy;
- card layout;
- button positions;
- icon positions.
