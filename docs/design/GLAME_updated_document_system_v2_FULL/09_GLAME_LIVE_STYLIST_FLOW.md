# 09. GLAME — Live Stylist Flow

## Роль

Сценарий живого стилиста — это не отдельный лендинг.  
Это bottom sheet / modal или chat-entry, который открывается из разных источников:
- `/selection`;
- hero slide 07;
- block 6;
- product card;
- favorites.

---

## Рабочее время

Живой стилист работает:

```text
10:00–20:00 по МСК
```

В интерфейсе всегда указывать `по МСК`, потому что покупатель может быть из другого региона.

Статус рассчитывается по серверному времени МСК, не только по времени телефона.

---

## Card status

В рабочее время:

```text
На связи сейчас · до 20:00 по МСК
```

В нерабочее время:

```text
Сейчас не на связи · с 10:00 по МСК
```

---

## Bottom sheet — рабочее время

Заголовок:

```text
Стилист GLAME
```

Текст:

```text
Опишите задачу — стилист поможет подобрать украшение онлайн или пригласит в пространство, если нужна примерка.
```

Поле:

```text
Что хотите подобрать?
```

Placeholder:

```text
Например: украшение на каждый день, подарок, комплект к образу, серьги под форму лица…
```

Быстрые варианты:
- Для себя
- В подарок
- Под образ
- Нужен комплект
- Хочу примерить

CTA:

```text
Связаться со стилистом
```

---

## Bottom sheet — нерабочее время

Заголовок:

```text
Оставить заявку стилисту
```

Текст:

```text
Стилист GLAME ответит с 10:00 до 20:00 по МСК. Опишите задачу — мы подберем украшения под образ, повод или подарок.
```

CTA:

```text
Оставить заявку
```

Важно: не дублировать кнопку AI внутри bottom sheet, если AI already shown as отдельная карточка/панель рядом.

Можно мягко подсказать текстом:

```text
AI-подбор доступен на этом экране, если хотите начать подбор сразу.
```

Но без отдельной кнопки внутри заявки, если это дублирует сценарий.

---

## Что отправляется стилисту

Обязательно:
- source;
- scenario;
- created_at;
- working_hours_status;
- authorization status;
- user name / phone / city, если есть;
- request text;
- quick tags;
- favorite product ids, если есть;
- source product id, если пришел из карточки товара.

Если пользователь авторизован и данные доступны — добавить историю покупок:
- последние покупки;
- категории;
- бренды/линии;
- металл/цвет/фактура;
- размеры;
- средний уровень покупки / average item price;
- частота покупок;
- подарочные сценарии;
- города покупок.

История покупок не показывается пользователю как UI-блок.  
Это внутренний контекст для стилиста.

## Запреты

- Не превращать в длинную страницу.
- Не дублировать AI-кнопку без необходимости.
- Не скрывать статус рабочего времени.
- Не писать “онлайн 24/7”, если живой стилист работает по графику.
- Не использовать мессенджерный зеленый/красный статус в стиле marketplace.
