# План интеграции SMS Aero

## Цель
Интегрировать API SMS Aero для отправки SMS-сообщений по результатам генерации. Добавить возможность отправки сообщений из интерфейса просмотра результатов генерации с настройкой времени и периодичности.

## Текущее состояние
- В бэкенде отсутствует сервис отправки SMS.
- В фронтенде есть просмотр результатов генерации (`GenerationHistoryPanel.tsx`), но нет кнопки отправки.
- API ключ предоставлен: `OkWzguVRgYPRgYme7l1wBAcextH3yj_L`.
- Логин (email) для SMS Aero: **ТРЕБУЕТСЯ УТОЧНЕНИЕ**.

## Архитектура решения

### 1. Бэкенд (Python/FastAPI)

#### 1.1. Сервис SMS Aero (`backend/app/services/sms_service.py`)
Создать класс `SMSAeroService` для взаимодействия с API SMS Aero.
- **Методы**:
  - `send_sms(number: str, text: str, sign: str = "SMS Aero", date_send: int = None)`: Отправка одного сообщения.
  - `send_bulk_sms(numbers: list[str], text: str, ...)`: Массовая отправка (если поддерживается/необходимо).
  - `check_status(id: int)`: Проверка статуса.
- **Конфигурация**:
  - Добавить переменные окружения `SMS_AERO_EMAIL` и `SMS_AERO_API_KEY`.

#### 1.2. API Эндпоинт (`backend/app/api/communication.py` или `sms.py`)
Создать эндпоинт для инициирования рассылки по результатам генерации.
- **URL**: `POST /api/communication/generations/{id}/send`
- **Тело запроса**:
  ```json
  {
    "schedule_time": "2023-10-27T10:00:00", // ISO формат, МСК
    "periodicity": "..." // Уточнить формат и смысл
  }
  ```
- **Логика**:
  1. Получить результаты генерации по `id`.
  2. Извлечь номера телефонов и тексты сообщений.
  3. Для каждого сообщения вызвать `SMSAeroService.send_sms` с параметром `dateSend` (преобразовав время в unixtime).
  4. Если "периодичность" подразумевает сложную логику (например, повторять каждые N дней), потребуется планировщик задач (Celery/APScheduler) на нашей стороне. Если это просто "отложенная отправка", то `dateSend` достаточно.

### 2. Фронтенд (React/Next.js)

#### 2.1. Модальное окно отправки (`SendSmsModal.tsx`)
Создать компонент модального окна, открывающегося по кнопке "Отправить".
- **Поля**:
  - "Время отправки (МСК)": `input type="datetime-local"`.
  - "Периодичность": `select` или `input` (нужно уточнить требования).
  - Кнопка "Подтвердить".

#### 2.2. Интеграция в `GenerationHistoryPanel.tsx`
- Добавить кнопку "Отправить" рядом с кнопкой "Экспорт".
- При нажатии открывать `SendSmsModal`.
- При подтверждении вызывать API бэкенда.

2. **Периодичность**: Что именно подразумевается под "периодичностью"?

   - Вариант Б: Регулярная отправка (например, "каждую пятницу").
   - Вариант В: Дробление рассылки (отправлять по 100 смс каждые 5 минут).
3. **Имя отправителя (Sign)**: Какое имя отправителя использовать? По умолчанию в SMS Aero часто используется "SMS Aero" или нужно зарегистрированное имя (например, "GLAME").
4. **Бюджет/Лимиты**: Есть ли ограничения на количество смс или бюджет, которые нужно учитывать при массовой отправке?
