# UI/UX спецификация мобильного приложения GLAME

Документ фиксирует структуру экранов и UX-паттерны (ориентир на iOS Human Interface Guidelines) для реализации в Flutter.

## 1) Онбординг (первый запуск)

3–4 экрана с ключевыми ценностями бренда в фирменном стиле:

1. Тройной контроль качества
2. Ручная работа и гипоаллергенные сплавы
3. Расширенная гарантия
4. Программа лояльности

Правила:
- показывается только при первом запуске (локальный флаг)
- CTA: “Начать” → ведёт на главный таб

## 2) Основной Tab Bar (5 разделов)

### 2.1 Главная (Home)

- Hero баннер: слайдер с коллекциями (Lookbook) и акциями, минималистичный дизайн, явный CTA
- Категории (иконки + текст): Кольца, Серьги, Колье, Браслеты, Чокеры/Каффы
- Преимущества (USP): горизонтальный скролл или сетка 2x3 с иконками и короткими текстами
- Хиты продаж / Новинки: горизонтальный скролл карточек товаров
- “О бренде”: краткий текст + кнопка “Подробнее” на отдельный экран

### 2.2 Каталог (Catalog)

- Древо категорий → при выборе категории открывается сетка товаров
- Фильтры: bottom sheet (как в Lamoda)
  - цена
  - металл (родий/золото)
  - тип застёжки
  - новинки
  - наличие
- Сортировка:
  - по популярности
  - по цене (возр./убыв.)
  - по новизне
- Отображение:
  - сетка 2 колонки
  - переключение на 1 колонку (детальнее, как в Lime)

### 2.3 Избранное (Wishlist)

- Сетка сохранённых товаров
- Свайп для удаления
- Интеграция с корзиной

### 2.4 Корзина (Cart)

- Минималистичный дизайн: товар → цена → количество
- Блоки: “Стоимость товаров”, “Доставка” (учёт бесплатной доставки от 10 000 ₽), “Итого”
- CTA: “Оформить заказ” (золотая)
- Отдельная индикация “Оплата при получении” (если метод доступен)

### 2.5 Профиль (Profile)

- Гостевой режим: показываем вход/регистрацию
- Личный кабинет: история заказов, адреса, бонусная программа, настройки уведомлений

Правило авторизации:
- приложение стартует без логина
- логин требуется только при переходе к покупке (checkout) или в личный кабинет

## 3) Ключевые экраны и функциональность

### 3.1 Экран товара (Product)

- Галерея: карусель фото с увеличением (pinch), индикатор количества фото
- Информация: название, цена, рассрочка/скидки (если есть)
- Выбор: размер/длина (если применимо)
- CTA:
  - “Добавить в корзину” (основная)
  - “В избранное” (сердце)
- Accordion:
  - Описание (материалы, гипоаллергенный сплав, родиевое покрытие)
  - Характеристики (вес, длина, тип застёжки)
  - Гарантия и уход (расширенная гарантия)
- “С этим также покупают”: горизонтальный скролл

### 3.2 Оформление заказа (Checkout)

- Прогресс: Корзина → Адрес → Оплата → Подтверждение
- Адрес: подсказки адреса (карты/геокодер)
- Доставка: стоимость зависит от суммы заказа и выбранного способа
- Оплата:
  - карта
  - оплата при получении (акцент/выделение)
- Итог: подтверждение заказа с номером

## 4) Технические требования

- Поддержка: iOS 15+ и Android
- Адаптивность: корректно на малых и больших экранах; safe area
- Производительность:
  - ленивая загрузка изображений + кэш
  - пагинация в каталоге
  - минимизация лишних перерисовок
- Анимации:
  - плавные переходы
  - анимация добавления в корзину
  - хаптика на ключевые действия
- Данные: REST API, типизированные модели
- Аналитика: базовый трекинг экранов и действий (Firebase)

## 5) Definition of Done (MVP)

- Визуальное соответствие дизайн-системе на всех ключевых экранах
- Корректные зоны нажатия (минимум 44×44 pt) и обратная связь
- Корзина и избранное сохраняют состояние между перезапусками
- Нет заметных просадок при скролле каталога с картинками
- Базовая аналитика подключена
