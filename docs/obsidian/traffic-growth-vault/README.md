# GLAME Traffic Growth

Изолированная рабочая база знаний агента `traffic-growth-agent` / Hermes-профиля
`glame-traffic-growth`.

Владелец базовых инструкций: **Anatoliy** (технические границы, доступы,
интеграции и изменения структуры). Маркетинговые, брендовые и публичные
материалы требуют согласования **Elena**.

## Разделы

- `00-briefs/` — утверждённые брифы, офферы, магазины и ограничения.
- `01-yandex/` — карты кампаний, гео, ключевые и минус-слова, чек-листы.
- `02-media/` — только каталог ассетов, ID, права и статус модерации.
- `03-reports/` — ежедневные и недельные отчёты.
- `04-experiments/` — гипотезы, A/B-тесты, решения и результаты.
- `99-runbook/` — инструкции по инцидентам и ручной передаче.

## Границы доступа

Агент читает весь vault и каталог доступных медиа. Он может записывать только
собственные черновики и отчёты в `03-reports/` и `04-experiments/`. Изменения
базовых инструкций и runbook делает только владелец. Секреты, OAuth-токены,
пароли, персональные данные клиентов и платёжные данные здесь не хранятся.
